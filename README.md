# Setup
1. Git clone this repository onto your computer, under your make Folder.
2. Open VS Code.
3. Create a new file called cond_make.py in this repository.

## Instructions

Have the user enter in their their grade as a percent (So, for example, the user will enter 78)

The program will output what level they achieved based off the following table

| Percent | Level Achieved |
|---------|----------------|
| 0-49    | Level 0        |
| 50-59   | Level 1        |
| 60-69   | Level 2        |
| 70-79   | Level 3        |
| 80-100  | Level 4        |

There is a hint on how to do this in the conditionals investigation.
